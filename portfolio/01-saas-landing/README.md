# Peça de Portfólio #01 — Flowly (SaaS Landing Page)

Landing page moderna e responsiva para um produto SaaS fictício (app de produtividade).
Projeto criado para demonstrar capacidade de **design + desenvolvimento front-end**.

## Como ver
- Abra o arquivo `index.html` com 2 cliques (abre no navegador), **ou**
- Para hospedar grátis: arraste a pasta `01-saas-landing` para [app.netlify.com/drop](https://app.netlify.com/drop) → você ganha um link `.netlify.app` pra mostrar a clientes.

## O que essa peça demonstra
- Layout responsivo (desktop, tablet e celular)
- Design system consistente (cores, tipografia, espaçamento)
- Componentes: hero, mockup de produto, features, pricing, depoimentos, FAQ com accordion
- Microinterações: animações ao rolar, menu mobile, hover states
- Código limpo, HTML semântico, sem dependências pesadas

## Tecnologias
HTML5 · CSS3 (sem frameworks) · JavaScript puro · Google Fonts (Inter)
