# Peça de Portfólio #02 — Sálvia (Restaurante / Bistrô)

Landing page calorosa e editorial para um restaurante mediterrâneo fictício.
Projeto criado para demonstrar **range de design** — estilo totalmente diferente da peça #01 (SaaS escuro).

## Como ver
- Abra `index.html` com 2 cliques (abre no navegador).
- Deploy fica por último (junto com as outras peças).

## O que essa peça demonstra
- Direção de arte **clara, calorosa e editorial** (paleta terracota/creme/sálvia)
- Tipografia serifada de personalidade (Fraunces) + sans limpa (Inter)
- Seções típicas de restaurante: menu com preços, galeria, chef, avaliações, reserva
- **Formulário de reserva funcional** (validação + estado de confirmação)
- Fotos gastronômicas reais (Unsplash, uso livre) — em produção, troca-se pelas fotos reais do cliente
- Hero com card 3D interativo (inclina seguindo o mouse) + galeria com tilt 3D no hover
- 100% responsivo

## Tecnologias
HTML5 · CSS3 (sem frameworks) · JavaScript puro · Google Fonts (Fraunces + Inter)
